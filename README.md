# Wikiang Theme for Angple

wikiang.org 전용 Angple 테마. 위키피디아 스타일 문서 중심 레이아웃.

## 기능

- 깔끔한 문서 중심 레이아웃
- 위키 링크 색상 시스템 (파란 링크 / 빨간 링크)
- 검색 중심 랜딩 페이지
- 위키 문서 타이포그래피 (h2 하단 구분선 등)
- 다크 모드 지원
- [angple/plugin-wiki](https://github.com/angple/plugin-wiki) 플러그인과 함께 사용

## 설치

```bash
git clone https://github.com/wikiang-org/wikiang-theme.git
cd wikiang-theme
./deploy/install.sh /path/to/angple
```

## 요구사항

- Angple Core >= 0.1.0
- [angple/plugin-wiki](https://github.com/angple/plugin-wiki) 플러그인
